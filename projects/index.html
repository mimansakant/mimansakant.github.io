The Customer Is Always Right (Even When They're Not): LLM Sycophancy Under Pressure

Do language models stick to a correct answer when a user pushes back? We took MMLU questions that each model answered correctly, then hit them with emotional appeals, logical counterarguments, and claims of expertise across two rounds of pressure, using an LLM judge to label each reply as holding, caving, or hesitating.

Across Claude Opus 4.6, GPT-5.2, DeepSeek-V3.2, and Llama 3.1 8B, claims of expertise were the most destabilizing pressure for every frontier model, and a second round of pushback produced more caving in every model we tested. Single-turn evals likely understate how sycophantic models really are.

QuantumGuard: Quantum Readiness Analyzer

A web app that checks how prepared a website or codebase is for quantum attacks. Paste in a URL and it inspects the TLS handshake for post-quantum cryptography support, or upload code and it scans for PQC libraries, then scores and ranks the results. There's also a Learn section explaining why PQC matters.

What I built: the code and folder analyzer that scans uploaded projects for PQC signature algorithms, its backend API, and the app's homepage.
